# nk2dl-gui

Welcome to `nk2dl-cli` (aka Nuke to Deadline CLI). `nk2dl-cli` is a commandline interface for submitting nukescripts from a shell. 

## Getting started

>[IMPORTANT!]
>`nk2dl-cli` is migrating from the `nk2dl` core. It is currently non-funcitonal.

- Install the [nk2dl](https://github.com/artandmath/nk2dl-core) python module if not done so already.
- Read the [documentation](http://artandmath.github.io/nk2dl-cli) to get `nk2dl-cli` up and running.
